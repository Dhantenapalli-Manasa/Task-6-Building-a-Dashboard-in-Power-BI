# 🎬 Movie Data Analysis Dashboard using Power BI

## 📌 Project Overview

This project was completed as part of my **Data Analytics Internship at TechnoHacks**.

The objective of this project was to design an interactive dashboard using **Microsoft Power BI** to analyze movie-related data. The dashboard presents meaningful insights through interactive visualizations, making it easier to explore trends and compare different aspects of the dataset.

---

## 🎯 Objectives

- Build an interactive dashboard using Microsoft Power BI.
- Create multiple visualizations to analyze movie data.
- Enable interactive data exploration using slicers and filters.
- Present insights in a clean, easy-to-understand report.

---

## 🛠️ Tools Used

- Microsoft Power BI Desktop
- Microsoft Excel (for basic data preparation)

---

## 📊 Dashboard Features

The dashboard includes the following visualizations:

- 📊 Bar Chart
- 📈 Line Chart
- 🥧 Pie/Donut Chart
- 📌 KPI Cards
- 🎛️ Interactive Slicers
- 📋 Summary Visualizations

These visualizations help users explore movie-related information interactively and gain useful insights from the data.

---

## 💡 Key Insights

The dashboard allows users to:

- Analyze movie data using interactive charts.
- Compare information across different categories.
- Explore trends using filters and slicers.
- View important metrics through KPI cards.
- Make data-driven observations using visual reports.
